Method

The region is tiled into H3 hexagons. Earth Engine computes zonal means for each cell from NLCD land cover, 3DEP terrain, GEDI canopy height, Hansen forest loss, Sentinel-2 seasonal indices, TIGER roads, HydroSHEDS rivers and PAD-US protected areas.

The Geo-AI layer is a random forest trained to separate GAP 1–2 protected land from unprotected background. Distance-to-protected is excluded as a predictor. High probability on unprotected land flags places that look like what the region already protects.

Each criterion is converted to a percentile rank from 0 to 1 across the region. Priority is the signed weighted sum, rescaled from 0 to 1. Corridors are least-cost paths across the hex graph with cell resistance (1 − priority)^k. Resistance is discounted through protected land and multiplied tenfold in heavily developed cells. The greenbelt network is the minimum spanning tree of least-cost links between the selected hubs.

Hub locations are approximate and should be verified before reporting.
