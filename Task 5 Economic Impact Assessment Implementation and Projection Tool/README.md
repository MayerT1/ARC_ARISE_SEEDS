# Task 5 · Economic Impact Assessment Implementation and Projection Tool (Mar 2027 – Mar 2028)

An end-user economic impact projection tool.

**SOW activities**
- Models estimating the economic contribution of tourism, workforce and conservation initiatives
- User-friendly interfaces for stakeholder use
- Real-world data inputs and scenario-based forecasting
- Tools supporting local and regional economic decisions

**Planned approach:** reads corridor scenarios exported by the Task 2+3 planner and applies the Task 4 indicator framework to project county and gateway-community outcomes. Candidate methods: input-output multipliers, travel cost, contingent valuation, hedonic pricing.

**Status:** planned. Starts March 2027.
